# Preserve Frontmatter Formatting demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Preserve Frontmatter Formatting](https://github.com/mnaoumov/obsidian-preserve-frontmatter-formatting) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **Preserve Frontmatter Formatting: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `preserve-frontmatter-formatting-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-preserve-frontmatter-formatting/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `preserve-frontmatter-formatting-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
